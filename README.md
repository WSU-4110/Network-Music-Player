# Network Music Player

Purpose
Network Music Player is an Android application that allows users to browse and play music files across devices connected through a network.

Functionality
  Browse music files
  Play and pause the music
  Playlist support
  Shuffle playback
  Network file access
  File browser integration

  Technologies Used
    Android Studio
    Java
    Gradle
    GitHub
    Tailscale
    SambaLite
