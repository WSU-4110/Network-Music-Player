#Installation Guide

System Requirements
  Windows 10 or  Windows 11
  Android Studio
  Android SDK
  Git

Clone the Repository 

git clone https://github.com/WSU-4110/Network-Music-Player.git

Open the project 
  Open Android Studio
  Select Open Project
  Choose the Network-Music-Player folder 

Build the project 
 Wait for Gradle Sync to finish
 Select Build > Make Project 

Run the application 
 Connect an Android device or start an emulator
 Press Run
 Launch the application
